# Practical 1: Deterministic Finite Automaton (DFA)

**Aim:** To design a DFA that accepts binary strings containing an even number of `1`s using JFLAP.

**Problem Statement:** Design a DFA over the alphabet `{0,1}` that accepts strings having an even number of `1`s.

**States:**
- q0 – Even number of 1s (Initial and Final State)
- q1 – Odd number of 1s

**Testing:** The automaton was tested with different binary strings to verify accepted and rejected inputs.

**Result:** The DFA was successfully designed and tested using JFLAP.
