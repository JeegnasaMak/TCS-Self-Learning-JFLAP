# Practical 2: Non-Deterministic Finite Automaton (NFA)

**Aim:** To design an NFA that accepts binary strings containing `01` as a substring using JFLAP.

**Problem Statement:** Design an NFA over the alphabet `{0,1}` that accepts strings containing consecutive symbols `01`.

**States:**
- q0 – Initial State
- q1 – Intermediate State
- q2 – Final State

**Testing:** The NFA was tested with different binary strings containing and not containing the substring `01`.

**Result:** The NFA was successfully designed and tested using JFLAP.
