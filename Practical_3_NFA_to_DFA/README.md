# Practical 3: NFA to DFA Conversion

**Aim:** To design an NFA and convert it into an equivalent DFA using JFLAP.

**Problem Statement:** Design an NFA that accepts binary strings containing `101` as a substring and convert it into an equivalent DFA.

**Concepts Used:**
- Non-Deterministic Finite Automaton
- Subset Construction Method
- Deterministic Finite Automaton

**Testing:** The converted DFA was tested using binary strings containing and not containing `101`.

**Result:** The NFA was successfully converted into an equivalent DFA and tested using JFLAP.
