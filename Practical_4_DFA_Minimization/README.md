# Practical 4: DFA Minimization

**Aim:** To minimize a Deterministic Finite Automaton using JFLAP.

**Problem Statement:** Design a DFA that accepts binary strings ending in `1` and minimize it by identifying equivalent states.

**Concepts Used:**
- Equivalent States
- State Partitioning
- DFA Minimization

**Testing:** The original and minimized automata were tested using different binary strings.

**Result:** The DFA was successfully minimized using JFLAP while preserving its accepted language.
