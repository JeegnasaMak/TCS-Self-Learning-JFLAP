# Practical 5: Regular Expression to Finite Automaton

**Aim:** To convert a regular expression into an equivalent finite automaton using JFLAP.

**Problem Statement:** Convert the regular expression `(a+b)*abb` into an equivalent finite automaton.

**Concepts Used:**
- Regular Expressions
- Regular Languages
- NFA Construction
- NFA to DFA Conversion

**Testing:** The converted automaton was tested with strings ending and not ending in `abb`.

**Result:** The regular expression was successfully converted into an equivalent finite automaton using JFLAP.
