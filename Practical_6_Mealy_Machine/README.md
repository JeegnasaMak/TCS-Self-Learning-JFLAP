# Practical 6: Mealy Machine

**Aim:** To design a Mealy Machine that detects the substring `01` in a binary input string.

**Problem Statement:** Design a Mealy Machine that produces output `1` whenever the substring `01` is detected and `0` otherwise.

**States:**
- q0 – Initial State
- q1 – Previous input was `0`

**Concepts Used:**
- Mealy Machine
- Input and Output
- State Transitions

**Testing:** The machine was tested with different binary input strings to verify the generated output sequences.

**Result:** The Mealy Machine was successfully designed and tested using JFLAP.
